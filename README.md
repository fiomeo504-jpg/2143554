# Random Task Generator

**Автор:** Хисматуллина Снежана Рамилевна

## Описание проекта

Графическое приложение для генерации случайных задач (учёба, спорт, работа) с сохранением истории в JSON, фильтрацией и возможностью добавления своих задач.

### Возможности:
- 🎲 Случайная генерация задачи из готового списка
- ➕ Добавление своей задачи (с выбором типа)
- 🔍 Фильтрация истории по типу задачи
- 💾 Автоматическое сохранение/загрузка истории из `tasks.json`
- ✅ Валидация ввода (пустые строки запрещены)

## Требования

- Python 3.7+
- Стандартные библиотеки (tkinter, json, random, os)

## Запуск

```bash
python main.py
