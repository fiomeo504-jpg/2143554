# Expense Tracker — Трекер расходов

**Автор:** Хисматуллина Снежана Рамилевна

## Описание программы

GUI-приложение для отслеживания личных финансов. Позволяет вести учёт расходов, фильтровать записи по категории и дате, а также подсчитывать сумму расходов за выбранный период.

### Функциональность:
- **Добавление расходов** (сумма, категория, дата)
- **Фильтрация** по категории и диапазону дат
- **Подсчёт суммы** расходов за произвольный период
- **Сохранение и загрузка** данных в JSON-файл
- **Удаление** записей
- **Автоматическая нумерация** записей (ID)
- **Статистика** (общее количество расходов и сумма)
