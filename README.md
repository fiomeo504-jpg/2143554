# 🎲 Random Task Generator

**Автор:** Хисматуллина Снежана Рамилевна

## 📌 Описание проекта

Графическое приложение для генерации случайных задач с возможностью:
- 🎲 Случайная генерация задачи
- ➕ Добавление своих задач с выбором типа
- 🔍 Фильтрация истории по типу (учёба/спорт/работа/все)
- 💾 Автоматическое сохранение и загрузка из JSON
- ✅ Валидация ввода (пустые строки запрещены)

## 🛠 Требования

- Python 3.7+
- Стандартные библиотеки (tkinter, json, random, os)

## 🚀 Запуск

```bash
python main.py
